Topic 02 Modelling a Toy Block in Autodesk Fusion
📄 Create a New Design File

In the Fusion home screen, click New Design to open a blank 3D workspace. The design file is saved to the cloud automatically under your Autodesk account. Name the file Toy_Block_v1 using File → Save before starting any modelling work.

Autodesk Fusion — New Design
Fig 3.2.1 Creating a new design file in Autodesk Fusion
✏️ Create a New Sketch on the XY Plane

In the Solid tab, click Create Sketch and select the XY Plane (the bottom face of the 3D space). The canvas enters sketch mode with a 2D grid. All 2D shapes drawn here will later be extruded into 3D geometry to form the base of the toy block.

Autodesk Fusion — Create Sketch
Fig 3.2.2 Selecting the XY plane to begin a new sketch
⬜ Draw the Base Rectangle

Use the Rectangle → Center Rectangle tool from the sketch toolbar. Click the origin point as the centre, then drag and set dimensions of 32 mm × 32 mm using the dimension input boxes. This forms the base footprint of a standard toy block. Press Escape to exit the tool.

Autodesk Fusion — Rectangle Sketch
Fig 3.2.3 Drawing a 32×32 mm centre rectangle as the block base
📐 Add Sketch Dimensions

Press D to activate the Sketch Dimension tool. Click each side of the rectangle and enter exact values — 32 mm for both width and depth. Fully constrained sketches turn black in Fusion, confirming all geometry is locked and defined before extrusion.

Autodesk Fusion — Sketch Dimensions
Fig 3.2.4 Applying 32 mm sketch dimensions — sketch fully constrained
⬆️ Extrude the Base Body

Click Finish Sketch to exit 2D mode. From the Solid toolbar, select Create → Extrude (shortcut E). Click the rectangle profile and set the extrusion distance to 11.4 mm — the standard height of a toy block. Click OK to create the solid base body.

Autodesk Fusion — Extrude
Fig 3.2.5 Extruding the base rectangle 11.4 mm to create the block body
🔘 Sketch the Stud (Top Circle)

Click the top face of the block body and create a new sketch. Use the Circle → Center Diameter Circle tool to draw a circle at the centre of the top face with a diameter of 10.8 mm — the standard stud diameter. This will be extruded upward to form the classic toy block knob.

Autodesk Fusion — Circle Sketch on Top Face
Fig 3.2.6 Drawing a 10.8 mm diameter circle for the toy block stud
⬆️ Extrude the Stud

Finish the sketch and use Extrude on the circle profile. Set the height to 1.8 mm with the operation set to Join so the stud merges with the base body as a single solid. Click OK. The toy block now has its characteristic top knob.

Autodesk Fusion — Extrude Stud
Fig 3.2.7 Extruding the stud 1.8 mm with Join operation
🔁 Rectangular Pattern the Studs

Use Create → Pattern → Rectangular Pattern to duplicate the stud. Select the stud body, set 2 instances in X (spacing 16 mm) and 2 instances in Y (spacing 16 mm). This creates a 2×2 grid of studs — the classic single-unit toy block configuration.

Autodesk Fusion — Rectangular Pattern
Fig 3.2.8 Rectangular pattern creating a 2×2 grid of studs on top
🕳️ Shell the Block Body

Use Modify → Shell to hollow out the block from the bottom face. Select the bottom face as the face to remove, and set the inside thickness to 1.6 mm. This creates the hollow underside characteristic of real toy blocks, reducing material while maintaining structural strength.

Autodesk Fusion — Shell Operation
Fig 3.2.9 Shell operation hollowing out the block with 1.6 mm wall thickness
🔵 Add Fillet to Edges

Use Modify → Fillet to round the top outer edges of the block with a radius of 0.5 mm. Fillets make the model more realistic and manufacturable — sharp edges on injection-moulded plastic parts are avoided in real product design to reduce stress concentration points.

Autodesk Fusion — Fillet Edges
Fig 3.2.10 Applying 0.5 mm fillet to the top outer edges of the block
🎨 Apply a Material & Appearance

Open the Appearance dialog (A key). Drag a Plastic — Glossy material from the library onto the block body. Choose a colour (we used red to match classic toy block styling). The 3D viewport updates in real time to preview the final appearance.

Autodesk Fusion — Appearance Panel
Fig 3.2.11 Applying glossy red plastic material to the toy block
🔍 Inspect the Model

Use Inspect → Measure to verify key dimensions of the finished model — overall height, stud diameter, and wall thickness. All values should match the design intent. Use Orbit (Middle Mouse Button) and Pan to inspect the model from all angles.

Autodesk Fusion — Measure Tool
Fig 3.2.12 Using the Measure tool to verify model dimensions
🖼️ Render the Final Model

Switch to the Render workspace from the top-left dropdown. Click Render to generate a photorealistic preview of the toy block. Fusion's cloud renderer produces a high-quality image showing the red glossy material, lighting, and shadows — demonstrating the professional output quality achievable.

Autodesk Fusion — Render Workspace
Fig 3.2.13 Photorealistic render of the completed toy block model
💾 Save the Design to Cloud

Press Ctrl + S to save the design. Fusion saves the file to the Autodesk cloud under your account — accessible from any device. The file is versioned automatically, so every saved state is preserved and can be rolled back at any point in time.

Autodesk Fusion — Cloud Save
Fig 3.2.14 Saving the toy block design to Autodesk cloud storage
📤 Export as STL

Right-click the top-level component in the browser panel and select Save As Mesh → STL. Set refinement to High and click OK. The .stl file is the universal format for 3D printing — exporting confirms the model is clean, watertight, and ready for physical fabrication.

Autodesk Fusion — Export STL
Fig 3.2.15 Exporting the toy block as an STL file for 3D printing
✅ Final Model Review

The completed toy block model is reviewed from all angles in the Fusion viewport. The design features a 32×32 mm base, 11.4 mm height, 2×2 stud array, 1.6 mm hollow walls, and 0.5 mm edge fillets — dimensionally accurate to a real toy block. Day 3 objective fully achieved.

Autodesk Fusion — Final Model
Fig 3.2.16 Completed toy block model — all features verified and dimensionally accurate

Printer 01 Bambu Lab H2D — Flagship Dual-Hotend Enclosed Printer
🔍 Overview

The Bambu Lab H2D is Bambu Lab's flagship enclosed 3D printer and the most advanced machine in the Tinkerers Lab. It has a fully enclosed chamber with a large front glass door, top glass cover, and side glass panels. During our visit it was actively printing with the AMS 2 Pro multi-filament system mounted on top, filament spools visible through its curved transparent lid, and the large 7-inch touchscreen showing real-time print progress.

Tinkerers Lab — Bambu Lab H2D
Fig 4.1.1 Bambu Lab H2D with AMS 2 Pro on top — actively printing in the Tinkerers Lab
📐 Key Specifications

Build Volume: 350 × 320 × 325 mm³  ·  Hotend Temperature: max 350°C  ·  Heatbed Temperature: max 120°C  ·  Nozzle Diameter: 0.4 mm standard (0.2 / 0.6 / 0.8 mm optional)  ·  Filament Diameter: 1.75 mm  ·  Hotend System: Dual (Left + Right)  ·  Machine Dimensions: 504 × 462 × 819 mm³  ·  Net Weight: ~38.5 kg  ·  Connectivity: Wi-Fi (IEEE 802.11 a/b/g/n)  ·  Slicer: Bambu Studio (also supports SuperSlicer, PrusaSlicer, Cura).

H2D PDF — Specifications Table

🧩 Printer Components

Key components identified on the H2D: Top Glass Cover (removable for maintenance), Side Glass Panels for visibility, Live View Camera with magnetic privacy cover, Heatbed supporting Textured PEI / Cool Plate / Engineering Plate / High Temperature Plate, Auxiliary Part Cooling Fan at the bottom, and a Status Indicator Light. On the rear: a Safety Key that must be inserted before the printer can power on — critical, the printer will not start without it.

🎨 AMS 2 Pro — Multi-Colour System

The AMS 2 Pro (Automatic Material System 2 Pro) sits on top of the H2D and holds up to 4 filament spools. Components: Filament Inlet & Outlet, Desiccant packs (keeps filament dry), Bambu Bus Port 6-pin, Active Support Shaft, and Air Vent. Connecting to the upper PTFE coupler → multi-colour with the right hotend; lower coupler → multi-colour with the left hotend. Two AMS 2 Pro units allow both hotends to print multi-colour independently at the same time.

H2D PDF — AMS 2 Pro Component Introduction (top view)
Fig 4.1.4 AMS 2 Pro top view — Filament Inlet, Desiccant slots, Air Intake
🔌 AMS 2 Pro — Ports & Connections

The bottom of the AMS 2 Pro houses all connection ports: the Filament Outlet (PTFE tube goes from here to the printer), PTFE Tube Release Button, Bambu Bus Port 6-pin (data link to printer), Power Connector, Active Support Shaft (holds spools), Locking Tab, and Air Vent. The Bambu Bus 6-pin cable connects the AMS 2 Pro to the rear of the H2D to allow automated filament switching during multi-colour prints.

H2D PDF — AMS 2 Pro Component Introduction (bottom view)
Fig 4.1.5 AMS 2 Pro bottom — Filament Outlet, PTFE Release Button, Bambu Bus Port 6-pin, Power Connector, Active Support Shaft
🧵 Filament Compatibility

Ideal materials: PLA, PETG, TPU, ABS, ASA, PVA, PET  ·  Capable: PA (Nylon), PC (Polycarbonate) — enabled by the 350°C hotend and 120°C bed  ·  With hardened nozzle: Carbon Fibre reinforced & Glass Fibre reinforced polymers. The H2D's high-temperature capability makes it the only printer in the lab able to handle the full range of engineering polymers without a nozzle upgrade.

📲 Binding & Using Bambu Studio

The H2D connects to Bambu Studio on PC via the same Wi-Fi network. In Bambu Studio, click Device → + to auto-discover the H2D. Bind it by clicking the detected printer. From Bambu Studio you can: send print jobs wirelessly, view the live camera feed, monitor temperatures and progress, pause or stop prints remotely, and update firmware. The Bambu Handy app on mobile provides the same control from anywhere via the cloud.

📊 A1 Mini vs A1 — Key Differences

The A1 Mini shares the same software ecosystem, workflow, and AMS Lite support as the full A1 but differs in three critical specs: Build volume — 180³ mm (Mini) vs 256³ mm (A1)  ·  Max bed temperature — 80°C (Mini) vs 100°C (A1)  ·  Power consumption — 150W (Mini) vs 1300W (A1). The A1 Mini is the best entry point for students and beginners — compact, quiet, and energy-efficient. The full A1 is better for larger prints or materials that need higher bed temperatures like PETG and PC.
