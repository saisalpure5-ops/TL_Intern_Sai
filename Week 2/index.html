Topic 01 Visual Studio Code — Installation & Setup
🌐 Visit the Official Website

Open your browser and navigate to code.visualstudio.com. This is the official Microsoft website for VS Code. Avoid downloading from third-party sources to ensure you get a clean, verified installer without any bundled software.

code.visualstudio.com/download
Fig 1.1.1 VS Code official download page on Microsoft's website
⬇️ Download the Installer

Click the large Download for Windows button (or your OS). The site auto-detects your operating system. The file downloaded is a standard .exe setup file roughly 90 MB in size.

code.visualstudio.com — Download button
Fig 1.1.2 Clicking "Download for Windows" on the VS Code page
📋 Accept the Licence Agreement

Run the downloaded installer. The first screen shows the End User Licence Agreement. Read through it, select I accept the agreement, and click Next to proceed to the installation path selection screen.

VS Code Setup — Licence Agreement
Fig 1.1.3 Accepting the VS Code licence agreement
📁 Choose Installation Path

On the Select Destination Location screen, keep the default path (C:\Users\{name}\AppData\Local\Programs\Microsoft VS Code) unless you have a specific reason to change it. Click Next.

VS Code Setup — Select Destination
Fig 1.1.4 Default installation directory — kept as-is
⚙️ Enable Critical Options

On the Select Additional Tasks screen, tick these two critical boxes: "Add to PATH" — allows launching VS Code from any terminal with code . — and "Open with Code" — adds VS Code to the Windows right-click context menu. Both options are extremely useful day-to-day.

VS Code Setup — Additional Tasks
Fig 1.1.5 Enabling "Add to PATH" and "Open with Code" options
🚀 Complete Installation

Click Install. The progress bar runs for about 30–60 seconds. Once done, keep Launch Visual Studio Code ticked and click Finish. VS Code opens automatically for the first time.

VS Code Setup — Installation Complete
Fig 1.1.6 Installation complete — "Launch VS Code" ticked
🧩 Install Essential Extensions

VS Code opens on the Welcome tab. Click the Extensions icon in the Activity Bar (or press Ctrl+Shift+X) and install: Prettier – Code formatter, ESLint, and GitLens. These three extensions are standard in every professional web development workflow.

VS Code — Extensions Marketplace
Fig 1.1.7 Installing Prettier, ESLint and GitLens from the marketplace
✅ Verify Installation

Open a terminal (Ctrl + `) inside VS Code and type code --version. The installed version number should print. This confirms VS Code is correctly added to the system PATH and is ready for use throughout the internship.

VS Code — Integrated Terminal
Fig 1.1.8 Running code --version to verify correct installation
💡
Quick Tip

Press Ctrl + ` to open the integrated terminal at any time. It automatically opens in the folder of your currently open project — no need to navigate separately.

Topic 02 GitHub — Account & Repository Setup
🌐 Open GitHub Website

Open your browser and go to github.com. GitHub is a cloud-based version control platform built on Git — the world's most widely used distributed version control system. Click Sign Up in the top-right corner.

github.com
Fig 1.2.1 GitHub homepage — clicking Sign Up to create an account
📝 Fill Registration Form

Enter your email address, choose a username (this becomes your public GitHub handle — choose professionally), and set a strong password. GitHub will send a verification code to your email to confirm it.

github.com/signup
Fig 1.2.2 Filling in the GitHub registration form with email and username
📧 Verify Email Address

GitHub sends a 6-digit verification code to your registered email. Open your inbox, copy the code, and paste it on the GitHub verification screen. Email verification is mandatory before you can create repositories.

github.com — Email Verification
Fig 1.2.3 Entering the 6-digit code from the verification email
👤 Complete Profile Setup

Go to Settings → Profile and add a profile photo, bio, and institution name (Sanjivani College of Engineering). A complete profile makes it easy for mentors and teammates to identify you in pull requests, issues, and code reviews.

github.com/settings/profile
Fig 1.2.4 Completing the GitHub profile with photo and bio
➕ Create New Repository

Click the + icon in the top-right → New repository. Name it sanjivani-internship-2026. Choose Public visibility so the mentor can review it. Tick Add a README file — this creates the default main branch automatically.

github.com/new
Fig 1.2.5 Creating the internship repository on GitHub
📄 Add Licence & .gitignore

Still on the new-repository screen, select MIT from the licence dropdown and choose Node from the .gitignore template dropdown. The .gitignore prevents node_modules/ and environment files from being accidentally pushed to GitHub.

github.com/new — Licence & .gitignore
Fig 1.2.6 Selecting MIT licence and Node .gitignore template
🔗 Clone Repository Locally

Click the green Code button on your new repository page and copy the HTTPS URL. Open VS Code's integrated terminal and run git clone <URL> to download the repository to your local machine. This links your local folder to GitHub.

github.com/username/sanjivani-internship-2026
Fig 1.2.7 Copying HTTPS URL to clone the repository locally
✅ Make First Commit

Open the cloned folder in VS Code. Edit README.md to add your name and internship details. In the terminal run git add . then git commit -m "Initial commit" then git push. Refresh GitHub — your changes are now live on the remote repository.

VS Code — Terminal (git push)
Fig 1.2.8 First commit pushed successfully — repository live on GitHub
✅
Day 1 Complete

VS Code is installed and configured. GitHub account is set up, repository created, and first commit pushed. The development environment is fully operational for the rest of the internship.
