CH 01

Introduction

Overview, problem statement, end users & scope

1.1 Overview

Smart home automation is one of the most impactful applications of the Internet of Things (IoT). It allows users to control electrical devices such as lights, fans, and appliances using a smartphone or internet connection. With the rise of technology and the growing demand for convenience, traditional electrical systems are rapidly being replaced by intelligent automated systems.

In this project, a smart home system was developed using the ESP32 microcontroller. The system controls two devices — a Yellow Light with dimming control and a Red Light with ON/OFF control — using Wi-Fi connectivity and the ESP RainMaker mobile application. Manual switch control is also supported, ensuring operation even without internet access.

🔴

Red Light

Simple ON/OFF control via relay. Operates through both manual switch and mobile app simultaneously.

💡

Yellow Light (Dimmer)

Multi-level brightness control using capacitor-relay method. Provides 5 distinct brightness levels.

📱

ESP RainMaker

Cloud connectivity via ESP RainMaker app. Real-time status updates, OTA firmware updates, and scheduling.

1.2 Problem Statement

Traditional electrical systems have several limitations that this project addresses:

⚠️

Traditional Problems

  • No remote access capability
  • Manual operation always required
  • Energy wastage due to improper usage
  • No brightness control for lights
✅

This System Solves

  • Remote control via mobile app
  • Dimming functionality implemented
  • Manual & app control synchronized
  • Real-time status feedback

1.3 Scope & End Users

The project focuses on designing a smart home automation system using ESP32 to control lighting devices through both manual switches and a mobile application. The system can be extended to control more appliances, add voice control, and implement advanced automation features like scheduling and sensor-based control.

2.1 Hardware Specifications

i) ESP32 Development Board

The ESP32 is the main controller used in this project. It processes input signals from switches and the mobile app, and controls output devices accordingly. Widely used in IoT applications due to its built-in WiFi and Bluetooth capabilities.

  • Built-in WiFi and Bluetooth for wireless communication
  • Dual-core processor for fast performance
  • Low power consumption
  • Multiple GPIO pins for interfacing
  • High processing capability

ii) Relay Module

Relay modules act as electrically operated switches to control AC loads. The project uses a 4-channel relay module where HIGH input turns the relay OFF and LOW input turns it ON.

  • Supports high voltage (230V AC)
  • Provides electrical isolation between control and load
  • Easy to interface with ESP32 via GPIO
  • Reliable switching — HIGH → Relay OFF, LOW → Relay ON

Block diagram, circuit, pin connections, flowchart & source code

3.1 Block Diagram

The system architecture connects the mobile application through WiFi to the ESP32 controller, which drives relay modules to control AC loads. Manual switches feed input directly to ESP32, ensuring offline operation capability.

🔷
System Data Flow

Mobile App → WiFi → ESP32 → Relay Module → AC Loads (Red Light / Yellow Light Dimmer). Manual Switches → ESP32 (same relay control path). All status updates flow back to the app in real time.

  • Mobile application sends ON/OFF and brightness commands through WiFi
  • ESP32 receives these commands and processes them in real time
  • Manual switches also provide direct input to ESP32
  • ESP32 controls the relay module based on received input
  • Relays switch the AC supply to the connected lights
  • The dimmer circuit uses capacitors to control brightness levels
  • Red light operates as ON/OFF; yellow light operates as a dimmer

3.3 Software Flow Chart

The firmware flow starts with ESP32 initialization, GPIO configuration, and WiFi connection via ESP RainMaker. After connecting, it loads last saved device states from EEPROM, applies them to relays, and enters an idle loop. Any input — from switch or app — triggers relay updates and state saves.

  • START → Initialize ESP32 → Set GPIO modes for relays, switches, LED
  • Connect to WiFi via ESP RainMaker BLE provisioning
  • If WiFi fails → Blink LED and retry
  • Register Red Light and Yellow Light devices on RainMaker
  • Load last saved states from EEPROM → Apply to relays
  • Enter idle loop → Wait for input
  • Input from manual switch → Read switch state → Update device state
  • Input from mobile app → Receive command → Update device state
  • Control relays → Save current state → Send updated state to app
  • Loop continues until Stop / Power Off → END

3.4 Source Code

The complete ESP32 firmware is written in C++ using Arduino IDE with the ESP RainMaker SDK. Key functions include dimmerControl(level), setRelay(pin, state), button event handlers, and the RainMaker write callback.

C++ — ESP32 Firmware 
#include <EEPROM.h>
#include "RMaker.h"
#include "WiFi.h"
#include "WiFiProv.h"
#include <AceButton.h>
using namespace ace_button;

#define ENABLE_EEPROM  true
#define EEPROM_SIZE    10

const char *service_name = "Redmi Note 12 Pro 5G";
const char *pop          = "om112233";
char deviceName_1[]      = "Red Light";
char deviceName_4[]      = "Yellow Light";

// GPIO Pins
static uint8_t RelayPin1    = 23;
static uint8_t DimmerRelay1 = 5;
static uint8_t DimmerRelay2 = 18;
static uint8_t DimmerRelay3 = 19;
static uint8_t SwitchPin1   = 13;
static uint8_t SwitchPin4   = 27;
static uint8_t wifiLed      = 2;

// States
bool toggleState_1 = LOW;
bool toggleState_4 = LOW;
int  currLevel     = 0;
int  prevLevel     = -1;

// Dimmer Control
void dimmerControl(int level) {
    if (level == prevLevel) return;
    prevLevel = level;
    digitalWrite(DimmerRelay1, HIGH);
    digitalWrite(DimmerRelay2, HIGH);
    digitalWrite(DimmerRelay3, HIGH);
    delay(100);
    switch (level) {
        case 0: break;
        case 1: digitalWrite(DimmerRelay1, LOW); break;
        case 2: digitalWrite(DimmerRelay2, LOW); break;
        case 3:
            digitalWrite(DimmerRelay1, LOW);
            delay(50);
            digitalWrite(DimmerRelay2, LOW); break;
        case 4: digitalWrite(DimmerRelay3, LOW); break;
    }
}

// Relay Control
void setRelay(uint8_t pin, bool state) {
    digitalWrite(pin, !state);
}

// App Callback
void write_callback(Device *device, Param *param,
                    const param_val_t val, void *, write_ctx_t *) {
    const char *device_name = device->getDeviceName();
    const char *param_name  = param->getParamName();

    if (strcmp(device_name, deviceName_1) == 0) {
        if (strcmp(param_name, "Power") == 0) {
            toggleState_1 = val.val.b;
            setRelay(RelayPin1, toggleState_1);
            param->updateAndReport(val);
        }
    }
    if (strcmp(device_name, deviceName_4) == 0) {
        if (strcmp(param_name, "Power") == 0) {
            toggleState_4 = val.val.b;
            if (toggleState_4) dimmerControl(currLevel == 0 ? 4 : currLevel);
            else               dimmerControl(0);
            param->updateAndReport(val);
        }
        if (strcmp(param_name, ESP_RMAKER_DEF_BRIGHTNESS_NAME) == 0) {
            currLevel = val.val.i;
            if (toggleState_4) dimmerControl(currLevel);
            param->updateAndReport(val);
        }
    }
}

// Loop
void loop() {
    button1.check();
    button4.check();
    digitalWrite(wifiLed, WiFi.status() == WL_CONNECTED);
}

CH 05

Discussion

Conclusion, advantages, limitations & future scope

5.1 Conclusion

The Smart Home Automation project successfully demonstrates an efficient and user-friendly system for controlling household electrical appliances using both manual switches and a mobile application. By integrating the ESP32 microcontroller with IoT technology, the system enables real-time control of devices with added dimming functionality.

The project effectively combines automation with manual control, ensuring users can operate devices even without internet connectivity. Proper synchronization between physical switches and the mobile application eliminates operational conflicts and ensures smooth performance. Integration with ESP RainMaker and voice control via Google Assistant further enhances user convenience.

🏆
Key Achievement

Successfully implemented a cost-effective (₹750) smart home system with reliable dual-control (manual + app), multi-level dimming, and voice control integration — fully functional without any conflicts between control methods.

5.2 Advantages & Limitations

✅

Advantages

  • Reduces manual effort via remote control
  • Supports both manual and app control simultaneously
  • Low-cost implementation (₹750 total)
  • Energy-efficient via controlled device usage
  • Real-time response with minimal delay
  • Easy to install and expand
⚠️

Limitations

  • Requires stable WiFi for app/cloud control
  • Relay-based dimmer provides step-based brightness
  • Relay switching produces audible clicking sound
  • Limited devices due to hardware constraints
  • Performance depends on network availability
